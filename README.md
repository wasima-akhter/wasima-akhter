# 🏗️ Architecture Overview

Demonstrating a **Feature-First Clean Architecture** with strict separation of concerns, high testability, and isolated layers:

```txt
lib/
│
├── core/
│   ├── network/          # Dio HTTP client, interceptors, error mapping
│   ├── constants/        # App colors, typography, theme & asset paths
│   ├── routes/           # Declarative navigation (GoRouter / GetX)
│   └── utils/            # Formatters, input validators, extensions
│
├── features/             # Feature-First Modular Structure
│   ├── auth/             # Persona KYC, Firebase, Google/Apple Sign-In
│   ├── streaming/        # Agora RTC engine & live video consultation
│   ├── chat/             # Socket.IO client, events & typing indicators
│   ├── marketplace/      # Product/fuel catalog & Google Maps tracking
│   ├── meal_planner/     # Offline-First Drift SQLite & OpenAI GPT API
│   └── monetization/     # Stripe payment sheets & RevenueCat paywalls
│       ├── data/         # Data sources (remote/local), DTO models
│       ├── domain/       # Entities, repository interfaces, use cases
│       └── presentation/ # Riverpod / BLoC / GetX controllers & screens
│
├── shared/
│   ├── widgets/          # Reusable UI component library, shimmer skeletons
│   └── services/         # Local storage (Drift, Hive), FCM notifications
│
└── main.dart             # Dependency injection (GetIt), app initialization
```
